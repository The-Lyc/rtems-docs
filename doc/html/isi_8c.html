Workaround for ISI CFG2 register read.

Note
The ISI_CFG2[31:27] can be written correctly, because the input writing data are assigned directly to the internal control bits as specified, the mismatch only happens in reading operation. [31:28] are shift right 1 bit, so [31:27] can be read from [30:27].

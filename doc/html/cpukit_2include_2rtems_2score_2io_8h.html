Outputs the source buffer in base64 encoding.

After word length of output characters produced by the encoding a word break is produced.

Parameters
put_charThe put character function.
argThe argument passed to the put character function.
srcThe pointer to the source buffer begin.
srclenThe length of the source buffer in bytes.
wordbreakThe word break string.
wordlenThe word length in bytes. If the word length is less than four, then a word length of four will be used.
Returns
The count of output characters.

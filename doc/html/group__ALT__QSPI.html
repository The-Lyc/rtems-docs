Detailed Description

This module defines a low level driver API for the hardware processor system (HPS) quad serial peripheral interface (QSPI) flash controller for access to serial NOR flash devices. The quad SPI flash controller supports standard SPI flash devices as well as high-performance dual and quad SPI flash devices.

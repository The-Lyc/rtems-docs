54 /*
55  * Register : Status Register - stat
56  *
57  * The STAT register contains bits that indicate the reset source or a timeout
58  * event. For reset sources, a field is 1 if its associated reset requester caused
59  * the reset. For timeout events, a field is 1 if its associated timeout occured as
60  * part of a hardware sequenced warm/debug reset.
61  *
62  * Software clears bits by writing them with a value of 1. Writes to bits with a
63  * value of 0 are ignored.
64  *
65  * After a cold reset is complete, all bits are reset to their reset value except
66  * for the bit(s) that indicate the source of the cold reset. If multiple cold
67  * reset requests overlap with each other, the source de-asserts the request last
68  * will be logged. The other reset request source(s) de-assert the request in the
69  * same cycle will also be logged, the rest of the fields are reset to default
70  * value of 0.
71  *
72  * After a warm reset is complete, the bit(s) that indicate the source of the warm
73  * reset are set to 1. A warm reset doesn't clear any of the bits in the STAT
74  * register; these bits must be cleared by software writing the STAT register.
75  *
76  * Register Layout
77  *
78  * Bits | Access | Reset | Description
79  * :--------|:-------|:------|:-------------------------------------
80  * [0] | RW | 0x0 | Power-On Voltage Detector Cold Reset
81  * [1] | RW | 0x0 | nPOR Pin Cold Reset
82  * [2] | RW | 0x0 | FPGA Core Cold Reset
83  * [3] | RW | 0x0 | CONFIG_IO Cold Reset
84  * [4] | RW | 0x0 | Software Cold Reset
85  * [7:5] | ??? | 0x0 | *UNDEFINED*
86  * [8] | RW | 0x0 | nRST Pin Warm Reset
87  * [9] | RW | 0x0 | FPGA Core Warm Reset
88  * [10] | RW | 0x0 | Software Warm Reset
89  * [11] | ??? | 0x0 | *UNDEFINED*
90  * [12] | RW | 0x0 | MPU Watchdog 0 Warm Reset
91  * [13] | RW | 0x0 | MPU Watchdog 1 Warm Reset
92  * [14] | RW | 0x0 | L4 Watchdog 0 Warm Reset
93  * [15] | RW | 0x0 | L4 Watchdog 1 Warm Reset
94  * [17:16] | ??? | 0x0 | *UNDEFINED*
95  * [18] | RW | 0x0 | FPGA Core Debug Reset
96  * [19] | RW | 0x0 | DAP Debug Reset
97  * [23:20] | ??? | 0x0 | *UNDEFINED*
98  * [24] | RW | 0x0 | SDRAM Self-Refresh Timeout
99  * [25] | RW | 0x0 | FPGA manager handshake Timeout
100  * [26] | RW | 0x0 | SCAN manager handshake Timeout
101  * [27] | RW | 0x0 | FPGA handshake Timeout
102  * [28] | RW | 0x0 | ETR Stall Timeout
103  * [31:29] | ??? | 0x0 | *UNDEFINED*
104  *

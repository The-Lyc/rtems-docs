void bsp_fdt_copy ( const void *  src)

Copies the specified source FDT to a dedicated global data area.

The source FDT is usually provided by a bootloader and may be located in a memory area that is used by the program. The low-level initialization should copy the FDT for later use.

The copy can be accessed by bsp_fdt_get().

Parameters
[in]srcThe source FDT.

void* rtems_debugger_arm_debug_registers ( void  )

ARM Debug registers

Return the debugger registers for you BSP if the SoC requires memory mapped registers and the DBGDRAR and DBGDSAR are not support or return 0. This function is provided in the ARM backend and declared weak.
